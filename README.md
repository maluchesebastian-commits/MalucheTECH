# MalucheTECH

**"MalucheTECH: Innovamos hoy, programamos el futuro."**

Sitio web corporativo de **MalucheTECH**, una empresa ficticia de desarrollo de software con sede en **La Dorada, Caldas, Colombia**. Este proyecto fue desarrollado como actividad académica, con apoyo de una herramienta de Inteligencia Artificial, para simular el ciclo real de creación, publicación y actualización de un sitio web corporativo.

## 📖 Descripción

MalucheTECH es una empresa dedicada al desarrollo de soluciones de software innovadoras y personalizadas. Ofrece servicios de creación de aplicaciones, sistemas web y programas empresariales, además de mantenimiento y soporte técnico. Su objetivo es ayudar a personas y empresas a mejorar sus procesos mediante la tecnología, con soluciones eficientes, seguras y fáciles de utilizar.

## 🛠️ Servicios

1. **Desarrollo de aplicaciones y sistemas personalizados** — creación de programas, aplicaciones web y móviles adaptados a las necesidades de cada cliente.
2. **Mantenimiento y soporte de software** — corrección de errores, actualizaciones, mejoras de seguridad y soporte técnico.

## 🎨 Identidad visual

- **Colores:** blanco, negro y rojo.
- **Tipografías:** Space Grotesk (títulos), Inter (texto) y JetBrains Mono (elementos tipo código/terminal).
- **Elemento distintivo:** una terminal animada en el encabezado que "escribe" comandos relacionados con el trabajo de la empresa, reforzando su identidad tecnológica.

## ✅ Secciones incluidas

- Encabezado con navegación y logo.
- Hero con propuesta de valor y terminal animada.
- Servicios (2 tarjetas).
- Testimonios de clientes.
- Preguntas frecuentes (acordeón).
- Formulario de contacto + botón de contacto flotante siempre visible.
- Pie de página.

## 🚀 Cómo publicarlo en GitHub Pages

1. Crea un repositorio en GitHub (por ejemplo `maluchetech`).
2. Sube estos archivos manteniendo la misma estructura de carpetas.
3. Ve a **Settings → Pages**.
4. En **Branch**, selecciona `main` y la carpeta `/ (root)`.
5. Guarda los cambios; GitHub generará un enlace del tipo:
   `https://<tu-usuario>.github.io/maluchetech/`

## 💻 Cómo verlo localmente

Basta con abrir `index.html` en cualquier navegador. No requiere instalación ni dependencias, ya que es un sitio estático hecho con HTML5, CSS3 y JavaScript puro.
